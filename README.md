## 📂 Projects

### 🎯 FocusLens — Student Focus Platform
An ongoing backend project for a student-focused platform supporting Student and Parent accounts and parent–student access workflows.
- **Architecture:** Clean Architecture + CQRS + MediatR
- **Auth:** ASP.NET Core Identity, JWT, refresh-token rotation, email verification, password reset
- **Backend:** ASP.NET Core Web API, EF Core, SQL Server, FluentValidation
- **Testing & Observability:** xUnit, Serilog

### 🎓 EduBridge — University Team Collaboration Platform
A full-stack platform for managing university graduation projects, connecting Students, TAs, Doctors, and Admins.
- **Auth:** ASP.NET Core Identity, JWT, refresh tokens, email confirmation
- **Backend:** ASP.NET Core Web API + MVC, EF Core, SQL Server
- **Libraries:** Mapster, FluentValidation, Serilog, MailKit
